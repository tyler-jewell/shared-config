# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment or discrimination of any kind. Maintainers may remove
comments, commits or contributors that violate this. Report concerns privately to the repository owner via the
contact on their GitHub profile. Reports are handled confidentially.
